# CommentNotify

## 插件作用

通过 QQ 官方机器人和微信 iLink 向站长发送新评论通知。支持分别开启 QQ、微信，选择通知待审核或已发布的新评论，并查看每个渠道最近的发送结果。

评论提交后直接发送；审核操作不会再次通知。发送失败不会影响评论保存，也不会自动重发。

## 使用方法

1. 需要 Typecho 1.2 / 1.3、PHP 8.0+ 和 cURL 扩展。将插件放入 `usr/plugins/CommentNotify`，在后台启用并进入设置。旧版用户先停用，再重新启用并配置。
2. **QQ**：在 [QQ 开放平台](https://q.qq.com/) 创建机器人，填写 AppID、AppSecret 和接收类型，保持通知关闭并保存。
3. 将设置页显示的 QQ 回调地址填入平台事件订阅。地址须为公网可访问的 HTTPS；私聊订阅 `C2C_MESSAGE_CREATE`，群聊订阅 `GROUP_AT_MESSAGE_CREATE`。生成绑定码，在目标私聊发送完整绑定命令；群聊须 @机器人发送。回到后台刷新状态，确认接收 ID。也可手动填写已有的 OpenID；频道填写子频道 ID。
4. **微信**：点击「获取登录二维码」，用微信扫码确认，再点击「检查登录状态」。向机器人发送“绑定通知”，点击「同步微信接收人」，按提示完成绑定。
5. 开启需要的通知渠道，选择评论状态及是否附带文章链接，保存后分别发送测试通知。绑定、登录和测试均使用已保存的配置。

## 常见问题

**还需要安装 OpenClaw 或独立 QQ 服务吗？**

不需要，插件直接访问 QQ 官方 API 和微信 iLink 接口。

**QQ 接收 ID 可以填写 QQ 号或群号吗？**

不可以。私聊使用用户 OpenID，群聊使用群 OpenID，不同 AppID 的 OpenID 不通用。可用绑定码自动获取。QQ Webhook 验签和自动绑定需要 PHP sodium 扩展，手动填写 ID 的发送功能不依赖 sodium。

**QQ 发送失败怎么办？**

确认已添加机器人好友或将机器人加入群聊，并开通主动消息权限。平台提示链接域名不允许时，关闭「附上文章链接」。频道推送可能需要其他程序保持机器人 WebSocket 在线。

**微信提示登录或会话失效怎么办？**

登录失效时重新扫码；缺少会话上下文时，先向机器人发送消息，再同步接收人。主动发送受微信平台规则和会话有效期限制。退出微信登录会清除凭证、接收人和会话，并关闭微信通知。

**为什么评论没有通知？**

检查渠道开关、评论状态和保存结果。默认跳过已登录用户发表的评论，可开启「通知登录用户自己发表的评论」。垃圾评论、回响和审核操作不触发通知，也不会补发历史评论。

**为什么收到重复通知？**

检查其他插件是否也开启了评论通知。使用 Enhancement 时，关闭其中的「QQ 评论通知」。

**测试失败后会自动重试吗？**

不会。网络超时可能表示接口已接收，请先核对 QQ、微信中的消息，再手动发送测试。每个渠道只保留最近一条结果。

**AppSecret 留空会清除吗？**

不会，留空保留已保存的密钥；更换 AppID 时必须重新填写 AppSecret。
